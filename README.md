# Instituto Alegrar

Site institucional estatico do Instituto Alegrar, criado com HTML, Tailwind CSS via CDN e JavaScript leve para animacoes de scroll e contadores.

## Publicacao

Este projeto foi preparado para GitHub Pages.

Arquivos principais:

- `index.html`
- imagens `.jpeg` usadas no layout
- `.nojekyll` para servir os arquivos como site estatico direto
